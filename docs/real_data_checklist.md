# Чек-лист проверки на реальных данных

Большая часть чек-листа выполнена 2026-10-03 (этапы 12–13, журнал в
`docs/rails_integration_plan.md`). Стенд: PostgreSQL 18 в Docker, macOS, 12 ядер. Данные —
выгрузки ФНС 2026.01.16 (локальный полный архив), 2026.02.03 и 2026.10.02 (частичная загрузка
субъектов 43 и 11) и 69 реальных дельт между ними. Осталось то, что требует данных и сервера
портала (раздел «Осталось»).

## Осталось (данные и сервер портала)

Команды — rake-задачи гема (`bundle exec rake -T gar`) или `bin/rails gar:…` в приложении;
`GAR_DATABASE_URL` — с правами импортёра (README, «Пользователи базы»).

1. **Сервер портала:** доступ к API и файловому серверу ФНС и время загрузки.

   ```bash
   bundle exec ruby examples/check_api.rb
   time bin/rails gar:update          # базы нет — частичная загрузка 43 и 11, импорт, пути, переключение
   bin/rails gar:status
   ```

2. **GUID улиц ФИАС из старой базы портала:**
   `ruby examples/verify_fias_guids.rb streets.csv > report.tsv` — сводка из stderr (сколько
   «совпадает», «другое название», «недействует», «не найден»).
3. **`Gar.match_house` по 5 881 адресу портала:** сколько `:exact`, `:fuzzy`, `:none`, и 10–20
   примеров `:none` с альтернативами.
4. **`Gar.address(guid)`** для 10–20 домов Кирова и Сыктывкара: `full_address` и `short_address`
   соответствуют правилам ФНС (`docs/Правила_формирования_адресной_строки.docx`).
5. **Автодополнение на вводах операторов портала:** дополнить
   `examples/benchmarks/queries_43_11.yml` реальными строками из формы и прогнать
   `ruby examples/benchmarks/search_quality.rb`.
6. **Крон:** `gar:update` по расписанию (README, «Rails»); через месяц — `gar:status` (дельты,
   размер схемы) и предупреждения дельт в логе о параметрах без записи объекта.

## Сверка цепочки дельт с полной выгрузкой (при необходимости повторить)

```bash
# база — текущая схема gar после цепочки дельт; полная выгрузка той же версии — в отдельную схему
ruby -e 'require "gar"; Gar.configure { _1.region_codes = %w[43 11] }; zip = Gar.download;
         c = Gar::Database.create_connection; s = Gar::Importer.new(c).import_full_base(zip, schema: "gar_full");
         Gar::PathBuilder.new(c, schema: s).build'
ruby examples/tools/check_consistency.rb gar
ruby examples/tools/compare_schemas.rb gar gar_full
```
