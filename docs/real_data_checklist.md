выгрузки ФНС 2026.01.16 (локальный полный архив), 2026.02.03 и 2026.10.02 (частичная загрузка

на реальной базе адресов приложения (выгрузка 2026.10.02), загрузка на рабочем сервере — 2026-10-10. Осталось — раздел
«Осталось».

## Осталось (данные приложения)

Команды — rake-задачи гема (`bundle exec rake -T gar`) или `bin/rails gar:…` в приложении;
`GAR_DATABASE_URL` — с правами импортёра (README, «Пользователи базы»).

1. **`Gar.address(guid)`** для 10–20 домов Кирова и Сыктывкара: `full_address` и `short_address`
   соответствуют правилам ФНС (`docs/Правила_формирования_адресной_строки.docx`).
2. **Автодополнение на вводах операторов:** дополнить
   `examples/benchmarks/queries_43_11.yml` реальными строками из формы и прогнать
   `ruby examples/benchmarks/search_quality.rb`.
3. **Крон:** `gar:update` по расписанию (README, «Rails»); через месяц — `gar:status` (дельты,
   размер схемы) и предупреждения дельт в логе о параметрах без записи объекта.

## Сверка цепочки дельт с полной выгрузкой (при необходимости повторить)

```bash
# база — текущая схема gar после цепочки дельт; полная выгрузка той же версии — в отдельную схему
ruby -e 'require "gar"; Gar.configure { _1.region_codes = %w[43 11] }; zip = Gar.download;
         c = Gar::Database.create_connection; s = Gar::Importer.new(c).import_full_base(zip, schema: "gar_full");
         Gar::PathBuilder.new(c, schema: s).build'
ruby examples/tools/check_consistency.rb gar
ruby examples/tools/compare_schemas.rb gar gar_full
```
