# Примеры гема GAR

Скрипты запускаются из корня репозитория: `bundle exec ruby examples/<скрипт>.rb`. Общая
настройка — `example_helper.rb`, из переменных окружения:

| Переменная | Что задаёт |
|---|---|
| `GAR_DATABASE_URL` | база ГАР (гем не читает `DATABASE_URL`); локально — `make dev-db-up`, `postgresql://postgres:postgres@localhost:6432/gar_db_dev` |
| `GAR_REGIONS` | субъекты через запятую: `43,11`; без неё — вся страна (полный архив ~50 ГБ) |
| `GAR_DOWNLOADS` | каталог архивов, по умолчанию `downloads` |
| `GAR_CA_FILE` | свой сертификат УЦ (корпоративный прокси), если его нет в хранилище ОС |

В Rails те же шаги выполняют rake-задачи `gar:*` (README, раздел «Rails»).

## Загрузка и обновление базы

| Скрипт | Что делает |
|---|---|
| `check_api.rb` | доступность API и файлового сервера ФНС, поддержка частичной загрузки |
| `1_download_full_database.rb [версия]` | скачивает выгрузку: с `GAR_REGIONS` — только файлы субъектов (~300 МБ на два) |
| `2_import_full_base.rb` | загружает последний скачанный архив с нужными субъектами в схему `gar_v<версия>` |
| `3_populate_full_paths.rb <схема>` | строит пути схемы — нужны поиску |
| `4_switch_to_imported_schema.rb <схема>` | делает готовую схему текущей |
| `5_search.rb ["строка адреса"]` | автодополнение, адрес по GUID, перенос старого адреса, `Gar::Search` |
| `6_update.rb` | `Gar.update!` — то, что запускает крон: дельты или полный импорт |

## Загрузчик (`downloader/`)

| Скрипт | Что делает |
|---|---|
| `show_latest_version.rb` | последняя выгрузка ФНС и ссылки на архивы |
| `list_all_versions.rb` | все выгрузки на сервере (около 8 месяцев): версия, полный архив, дельта |
| `get_version_by_id.rb [версия]` | сведения о выгрузке |
| `download_delta_updates.rb [версия]` | скачивает дельту в `config.delta_dir` |
| `cleanup_old_files.rb [--delete]` | старые архивы: показать или удалить |

## Проверка и замеры

| Файл | Что делает |
|---|---|
| `tools/check_consistency.rb [схема]` | инварианты схемы и пересчёт путей и рангов с нуля — после дельт |
| `tools/compare_schemas.rb <схема> <схема>` | сравнение двух схем: цепочка дельт против полной выгрузки |
| `benchmarks/search_quality.rb [queries.yml]` | качество автодополнения на типичных вводах (`queries_43_11.yml`) |
| `benchmarks/import_and_search.rb <zip>` | время импорта, путей и запросов поиска (p50/p95) |
| `benchmarks/generate_archive.rb` | синтетический архив заданного объёма |
| `verify_fias_guids.rb streets.csv` | сверяет GUID улиц ФИАС со схемой ГАР (README, «Перенос старых адресов») |
| `tools/gar_toc.py <zip или URL> 43 11 [--extract out.zip]` | оглавление архива без скачивания; `--extract` — архив нужных субъектов |
| `tools/gar_delta_probe.py` | оглавление и примеры записей последних дельт |
